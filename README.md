## ✨ Key Features
- **Professional Aesthetics**: 50+ templates covering F&B, Retail, Education, and System Alerts.
- **Drag-and-Drop Editing**: 100% compatible with [FlexCraft Visual Editor](https://liming.me).
- **Multi-language Support**: Optimized layouts for Traditional Chinese and Japanese markets.
- **Developer Friendly**: Clean JSON structures that follow LINE's latest rendering best practices.

## 📂 Project Structure
- `/jsons`: The source JSON files for all 50+ templates.
- `/previews`: High-resolution screenshots with a professional phone-shell mockup.

## 🛠️ Quick Start
1. **Browse**: Check the `previews/` folder to find a layout that fits your needs.
2. **Copy**: Open the corresponding `.json` file in the `jsons/` folder.
3. **Deploy**: Paste it into your LINE Messaging API code or the LINE OA Manager.
4. **Customize**: Want to change colors or layouts? Open it in **[FlexCraft](https://liming.me)**.
