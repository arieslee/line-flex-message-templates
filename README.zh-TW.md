## ⚙️ 開發者整合 (Developer Integration)
您可以直接讀取 `jsons/` 目錄下的檔案，並將內容傳遞至 LINE Messaging API。

**Node.js 範例：**
```javascript
const flexContents = require('./jsons/5_zh-TW_訂單確認.json');

// 使用 LINE SDK 發送訊息
client.replyMessage(event.replyToken, {
  type: 'flex',
  altText: '您的訂單已確認',
  contents: flexContents
});
```
