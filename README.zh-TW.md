## 🎨 為何選擇本專案？
- **海量範本**：內含 50 套以上覆蓋餐飲、電商、教育、系統警報等場景的設計。
- **100% 可視化修改**：所有 JSON 檔案皆可導入 [FlexCraft](https://liming.me)，無需改動任何代碼即可調整樣式。
- **符合官方規範**：結構精確，完美適配 iOS 與 Android 端的渲染差異。
- **開發者必備**：節省 90% 以上調整 Flex Message 佈局的時間。

## 📂 文件夾說明
- `/jsons`: 存放所有範本的 JSON 源碼，方便快速複製。
- `/previews`: 存放帶有手機殼質感的高清預覽圖。

## 🛠️ 如何使用
1. **挑選**：在 `previews/` 中找到你想要的設計。
2. **獲取**：在 `jsons/` 中開啟對應編號的檔案並複製內容。
3. **應用**：將代碼貼入你的 LINE Bot 開發環境。
4. **編輯**：若需修改內容或顏色，推薦使用 **[FlexCraft](https://liming.me)** 進行線上編輯。
