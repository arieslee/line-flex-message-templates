## 🎨 核心優勢

- **50+ 專業設計**：涵蓋各行各業，無需從零開始設計 JSON。
- **可視化編輯**：完美支援 [FlexCraft](https://liming.me)，像做 PPT 一样簡單。
- **Nuxt 4 優化**：結構輕量且符合 LINE 最新渲染規範。

## 🛠️ 使用方法

1. 在 `previews/` 目錄中瀏覽並挑選心儀的樣式。
2. 在 `jsons/` 目錄中找到對應的 JSON 檔案。
3. 直接複製代碼，或在 **[FlexCraft](https://liming.me)** 中進行二次修改。
